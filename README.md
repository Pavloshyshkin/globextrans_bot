# GlobexTrans — Telegram-бот для заявок

Бот приймає заявки від клієнтів на:
- 🚖 Пасажирські перевезення
- 📦 Відправку посилок

Кожна заявка зберігається в базі SQLite (`globextrans.db`) і одразу надсилається
адміністратору(ам) у Telegram з кнопками зміни статусу («В роботі» / «Виконано»).
Клієнт може переглянути свої заявки командою/кнопкою «📋 Мої заявки».

## 1. Створення бота

1. Напишіть у Telegram боту **@BotFather**.
2. Команда `/newbot`, дайте назву та юзернейм (наприклад `GlobexTransBot`).
3. Отримаєте **токен** виду `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — збережіть його.

## 2. Дізнатись свій chat_id (щоб отримувати заявки)

1. Напишіть боту **@userinfobot** — він покаже ваш `id`.
2. Якщо заявки мають приходити кільком менеджерам — зберіть кілька id через кому.
   Якщо хочете приймати заявки в груповий чат — додайте бота в групу і візьміть id групи
   (він буде від'ємним, наприклад `-1001234567890`).

## 3. Встановлення

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 4. Налаштування

Створіть файл `.env` у кореневій папці проекту:

```bash
BOT_TOKEN="ВАШ_ТОКЕН_ТУТАЙ"
ADMIN_CHAT_IDS="7555835227"   # ваш id (або кілька через кому)
LOG_LEVEL="INFO"              # DEBUG для детального логування
```

**Приклад (.env.example)**:
```bash
BOT_TOKEN=your_bot_token_here
ADMIN_CHAT_IDS=123456789,987654321
LOG_LEVEL=INFO
```

⚠️ **Важливо**: Не комітьте `.env` файл у Git! Додайте його у `.gitignore`.

**Встановіть залежності**:
```bash
pip install python-dotenv
```

## 5. Запуск

```bash
python bot.py
```

Бот запуститься в режимі long polling. Залиште процес працювати.

Логи покажуть:
```
✅ База даних ініціалізована
✅ Бот запустився. Чекаємо повідомлень...
```

Якщо логи не показуються достатньо:
```bash
LOG_LEVEL=DEBUG python bot.py
```

## 6. Як це виглядає для клієнта

1. `/start` → вітання + меню з кнопками.
2. Клієнт обирає «Пасажирські перевезення» або «Відправити посилку».
3. Бот покроково запитує деталі (звідки/куди, дата, контакти тощо).
4. Після завершення клієнт отримує номер заявки, а ви — повідомлення з усіма деталями
   та кнопками зміни статусу.

## 7. Команди адміністратора

- `/all` — переглядіть останні 50 заявок
- `/cancel` — скасувати заявку (для клієнта)
